Deterministic 4 KB Python chess engine using tapered piece-square tables, bishop pair, PVS, null-move pruning, 2-killer + history move ordering, reverse futility pruning, LMR, and aspiration windows.

## Run it

```sh
python3 -P -s main.py
```
